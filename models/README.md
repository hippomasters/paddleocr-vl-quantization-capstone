# Model checkpoints

The 8-bit and 4-bit modified VLM weights are in separate **public** Hugging Face model repositories: [W8A16](https://huggingface.co/adityatrha/PaddleOCR-VL-1.6-GPTQ-W8A16-G128) and [W4A16](https://huggingface.co/adityatrha/PaddleOCR-VL-1.6-GPTQ-W4A16-G128). The BF16 base is `PaddlePaddle/PaddleOCR-VL-1.6`. This GitHub repository intentionally contains no weights, layout model, benchmark images, calibration pages, or wheelhouses. See `config/checkpoint_hashes.json`, `evidence/public_model_release_20261031.json` and `evidence/full_run_archive_hashes.json` for verification. Both model repositories preserve the upstream Apache-2.0 LICENSE, add a modification NOTICE, and document GPTQ scope and limitations; the original reproduction/demo code in this GitHub repository is also Apache-2.0 licensed under its own `LICENSE` and `NOTICE`.
