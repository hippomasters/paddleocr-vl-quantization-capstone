# Model checkpoints

The 8-bit and 4-bit modified VLM weights live in the separate **private** Hugging Face model repositories `adityatrha/PaddleOCR-VL-1.6-GPTQ-W8A16-G128` and `adityatrha/PaddleOCR-VL-1.6-GPTQ-W4A16-G128`. The BF16 base is `PaddlePaddle/PaddleOCR-VL-1.6`. This GitHub repository intentionally contains no weights, layout model, benchmark images, calibration pages, or wheelhouses. See `config/checkpoint_hashes.json` and `evidence/full_run_archive_hashes.json` for verification. The model repositories preserve upstream Apache-2.0 LICENSE and describe the GPTQ modification; licensing for this project's original reproduction/demo code is a separate owner decision.
