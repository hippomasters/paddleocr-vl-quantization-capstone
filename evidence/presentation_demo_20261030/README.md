# Presentation demo · PPT-matched short edit

`presentation-demo-short.mp4` is a **48-second captioned edit** of a real localhost browser run on the RTX 4070 Laptop. It uses the supplied NMIMS capstone deck’s navy/teal/gold palette; long unchanged model-loading waits were shortened, not presented as real-time. The page is synthetic and clearly labeled, not an examiner input or the four-L4 benchmark. The three variants ran sequentially and wrote the Markdown/JSON/timing files in `outputs/`; `summary.json` records their exact SHA-256 hashes, measured warm page times and peak device memory. Captions were appended beneath real screenshots; no model output was generated for the video. Full unedited browser frames, server/client logs, and previous full-length recording remain in the separate local `capstone-evidence/` folder. The PPTX source itself is not redistributed here.
