# Laptop GPU synthetic smoke evidence

This is a **real localhost browser run** on the RTX 4070 Laptop 8 GB GPU, BF16 → private-Hub W8A16 → private-Hub W4A16 sequentially. The page was generated solely for functional validation; it is **not** an examiner page, benchmark input, accuracy test, or a replication of the four-L4 study. The Markdown, JSON, per-model timing files and comparison video were copied byte-for-byte from the local run or recording; `summary.json` gives SHA-256 hashes, per-model timings, peak device memory, and runtime settings. Video lasts 427 seconds at actual playback duration, recorded as one real browser screenshot per second, without generated model output. The full server/client logs and raw capture frames remain in the separate local `capstone-evidence/laptop-runs/` and `capstone-evidence/video-frames-synthetic/` folders. The demo UI accepts an arbitrary examiner image live; that future input is unverified until run.
